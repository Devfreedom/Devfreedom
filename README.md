## 👨🏽‍💻 About Me

I'm a **Junior Full-Stack Developer** focused on building responsive web interfaces and practical applications backed by APIs and databases. I enjoy turning ideas into working products and improving the details that make them dependable: authentication, authorization, validation, error handling, testing, and deployment.

- 🔭 **Building:** Full-stack applications, including Northbridge Health and SwiftDrop
- 🧰 **Main stack:** React, JavaScript, Tailwind CSS, Node.js, Express, and PostgreSQL

- 🤝 **Interested in:** constructive code reviews, collaboration, and useful open-source projects
