## 👨🏽‍💻 Engineering Profile

I'm a **Full-Stack Software Engineer** focused on shipping high-performance web applications, multi-role portals, and resilient backend APIs. I sweat the architectural details that make software dependable in production: role-based access control (RBAC), strict input validation, zero-dependency UI micro-interactions (`IntersectionObserver` & pure CSS keyframes with `prefers-reduced-motion` compliance), and optimized relational data models.

- 🔭 **Shipped & Active Systems:** [Crestfield Academy](https://crestfield-academy-sable.vercel.app), [Aura Suites & Apartments](https://github.com/Devfreedom/aura-suites-and-apartments), [Northbridge Health](https://github.com/Devfreedom/Medical_Healthcare_Platform), [SwiftDrop](https://github.com/Devfreedom/swiftdrop), and **Nairova**
- 🧰 **Core Stack:** Next.js, React, TypeScript, JavaScript, Tailwind CSS, Node.js, Express, and PostgreSQL (`pg` / Sequelize)
- ⚡ **Frontend Philosophy:** Sub-second perceived performance, accessible component primitives, and hardware-accelerated CSS motion without heavy third-party bundle bloat
- 🔐 **Backend Focus:** Parameterized SQL connection pooling, multi-tenant role authorization, structured error handling, and zero-downtime deployment workflows
